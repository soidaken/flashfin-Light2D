# flashfin-Light2D

基于 CocosCreater 实现的全平台可用的 2d 光照系统,简单高效易用.  
The 2d lighting system based on CocosCreater is simple, efficient and easy to use.

```
此插件已开发完成,还未上线商店,预计半个月内提交上线.
```
